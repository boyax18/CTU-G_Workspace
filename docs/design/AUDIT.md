# UI consistency audit (baseline 16 November 2026)

Findings from inspecting `frontend/src`. **Status: Open.** Nothing here has been fixed, and this document does not authorize any change. Fix an item only when a task covers that area, and record the fix in your report. Contrast ratios were computed with the WCAG 2.x relative-luminance formula against the flat token background.

Severity: **High** = an accessibility failure or a visible defect. **Medium** = inconsistency that agents will copy. **Low** = polish.
